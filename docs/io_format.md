Input and Output Data Formats

1. General Description

This document describes the data formats used within the DORIS-based
VTEC processing pipeline. The focus is on the structure of the data
tables generated and consumed by each processing stage. All datasets
are represented as tabular data and are typically stored using
column-oriented file formats such as Parquet.

2. Stage 1 Output: Raw STEC Products

Stage 1 generates intermediate Slant TEC (STEC) products. These
products are written to disk and serve as the primary input for Stage
2.

Each STEC product contains observation-level records with one row per
epoch per station–satellite pair.

Typical fields in the Stage 1 STEC output include the following.

obs_epoch
Datetime of the observation epoch.

station_code
Short string identifier of the DORIS station.

prn
String identifier of the satellite.

L1
Dual-frequency phase observation on the first frequency.

L2
Dual-frequency phase observation on the second frequency.

elevation
Elevation angle of the satellite as seen from the station, in degrees.

ipp_lat
Latitude of the ionospheric pierce point, in degrees.

ipp_lon
Longitude of the ionospheric pierce point, in degrees.

stec
Raw slant TEC value derived from dual-frequency phase observations.
This value includes an unknown constant bias.

Additional auxiliary fields related to geometry or quality control may
also be present, depending on configuration.

3. Stage 2 Input: STEC Products

Stage 2 reads the intermediate STEC products generated by Stage 1. No
modification of the STEC structure is required prior to Stage 2.

Records are grouped by station and satellite to form continuous
observation passes.

4. Stage 2 Output: Leveled VTEC Products

Stage 2 generates leveled Vertical TEC (VTEC) products. These products
are written to disk as the final output of the pipeline.

Each VTEC product contains pass-wise or epoch-wise records, depending
on configuration.

Typical fields in the Stage 2 VTEC output include the following.

obs_epoch
Datetime of the observation epoch.

station_code
Short string identifier of the DORIS station.

prn
String identifier of the satellite.

ipp_lat
Latitude of the ionospheric pierce point, in degrees.

ipp_lon
Longitude of the ionospheric pierce point, in degrees.

vtec
Leveled vertical TEC value after pass-wise offset correction.

pass_id
Identifier of the observation pass used for grouping and leveling.

elevation
Elevation angle of the satellite as seen from the station, in degrees.

ipp_lat
Latitude of the ionospheric pierce point, in degrees.

ipp_lon
Longitude of the ionospheric pierce point, in degrees.

Additional auxiliary fields related to geometry or reference data may
also be included.

5. External Reference Data

Global Ionospheric Map data are used as external reference input for
Stage 2. These data are not stored in the same tabular format but are
interpolated to match the observation epochs and ionospheric pierce
points of the STEC-derived data.

Interpolated reference values may be stored as auxiliary fields in the
Stage 2 output for diagnostic or validation purposes.

6. Notes

Field names and exact content may vary slightly depending on
configuration or future extensions. However, the core fields described
above form the stable interface between processing stages.
